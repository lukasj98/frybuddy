# FryBuddy Website

Statische Promo-Seite für die FryBuddy iOS-App.

**Live:** https://lukasj98.github.io/frybuddy/

## Lokal ansehen

```bash
cd ~/Desktop/frybuddy
python3 -m http.server 8080
```

Dann im Browser: http://localhost:8080

## Struktur

- `index.html` – Landing Page
- `css/styles.css` – Styles (Orange/Rot-Gradient, Glass-Look wie in der App)
- `js/main.js` – Mobile Navigation & Scroll-Animationen
- `assets/app-icon.jpg` – App-Icon aus dem Xcode-Projekt
- `assets/screenshots/` – App-Store-Design-Bilder
- `impressum.html` – Impressum
- `datenschutz.html` – Datenschutzerklärung (App & Website)
- `css/legal.css` – Styles für Rechtstexte
